# 홈페이지 디자인 시안

`index.html`은 검토 중인 독립 HTML 시안입니다. Next.js 페이지에 연결되지 않았으며 운영 디자인을 변경하지 않습니다.

## 미리보기

저장소 루트에서 다음 명령을 실행한 뒤 `http://127.0.0.1:8768/`을 엽니다.

```sh
python -m http.server 8768 --bind 127.0.0.1 --directory docs/design-preview
```

## 반영된 구성

- 화이트·차콜 바탕, 고딕 제목, 붉은 주황색 강조
- 기존 로고가 있는 헤더. 헤더 전화번호 제거
- 좌우 여백을 둔 중앙 배치와 최대 1,440px 너비
- 사진 위 소개 문구, 10장 슬라이드, 5초 자동 전환, 이전·다음·일시정지
- 사진 없는 복수 메뉴 선택과 식사 유무 선택. 선택 완료 시 행사 입력란 표시
- 메뉴 선택 테두리 한 줄, 섹션 간 여백, 행사 기록과 블로그 링크
- 확인된 사업자 정보·연락처·영업시간·바로가기 푸터
- 운영자 답변을 반영한 FAQ 5개

## 운영 반영 전 확인

- 견적 양식은 시안이며 실제 접수·메일 발송·DB 저장을 하지 않습니다.
- 블로그 사진은 검토 시점의 정적 목록이며 자동 동기화하지 않습니다. 일부는 저해상도 썸네일이므로 운영 반영 전 원본 교체가 필요합니다.
- 폰트와 사진을 보려면 인터넷 연결이 필요합니다.
- 검색 색인을 막는 `noindex, nofollow`는 시안 전용입니다.
- 실제 홈페이지 SEO 제목·설명 수정은 `src/app/page.tsx`에 별도로 반영되어 있습니다.
- 이 자료를 커밋하거나 머지하는 것만으로 배포하지 않습니다. 운영 배포는 별도 요청 후 진행합니다.
